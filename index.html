1. Project Overview

The Financial KPI Dashboard aims to provide a real-time, centralized view of key financial metrics (e.g., revenue, gross profit, net profit, and utilization rates). The backend service will connect to a MongoDB database, store data in year-specific collections, and serve these metrics through an API.

2. Objectives

2.1 Business Objectives

- Offer executives and finance teams quick, reliable, and consistent access to critical KPIs.
- Simplify data retrieval by year, quarter, and specific KPI type.

2.2 Technical Objectives

- Implement a scalable data model in MongoDB (one collection per year).
- Maintain an extensible Node.js/Express code structure for future expansions (new metrics, additional years).

3. Scope & Requirements

3.1 In-Scope

- RESTful API endpoints (GET routes) to fetch KPI data by year, quarter, or metric type.
- Error handling for invalid or missing data (returning 404 or 400 as appropriate).
- Logging/monitoring using integrated middleware (Morgan or a custom logger).

3.2 Out-of-Scope

- Complex analytics beyond retrieving stored values.
- Front-end UI or dashboard implementation (to be handled by a separate project).

3.3 Technical Requirements

- Node.js LTS (16+).
- MongoDB 4.4+ (local or Atlas).
- Environment variables for PORT and MONGODB_URI.

4. Stakeholders

Project Sponsor: Boxx Leadership / Finance Department
Technical Team: Full-stack developers, DevOps, QA
Finance Stakeholders: CFO, finance analysts
Others: External clients or third parties needing KPI access

5. Timeline / Roadmap

5.1 Phases

- Phase 1: Database schema design and backend architecture (Complete)
- Phase 2: Dashboard front-end integration with the API
- Phase 3: Security enhancements (authentication, HTTPS, etc.)
- Phase 4: Extended analytics (monthly data, advanced calculations)

6. Success Criteria

  • Reliable Data Retrieval: All key KPIs are accurate and up-to-date.
  • Low Latency: API requests return within acceptable time (<1s in normal scenarios).
  • Scalability: Minimal code changes needed to add new years or metrics.
  • Security & Compliance: Database credentials and sensitive information are protected.

7. Glossary

KPI (Key Performance Indicator): A measurable value that demonstrates how effectively a company is achieving its key objectives.
MongoDB: A NoSQL database storing data in flexible JSON-like documents.
Quarter (Q1–Q4): A three-month period in a company's financial year.
Utilization Rates: Percentage of available resources actively contributing to projects.
